# Numerical Methods for Root Finding 🧮

A simple Python project that solves non-linear equations and finds roots using three fundamental numerical methods. This project is perfect for students and beginners learning computational mathematics.

## 🚀 Features

This project includes basic Python implementations of the following algorithms:
1. **Bisection Method:** A reliable, bracketed method that repeatedly halves an interval to find the root.
2. **Newton-Raphson Method:** A fast, open method that uses the derivative of the function to converge quickly to the root.
3. **Fixed-Point Iteration:** A simple method that rewrites the equation as `x = g(x)` to find the solution through continuous iterations.

## 🛠️ Prerequisites

- Python 3.x installed on your computer.
- No external libraries are required (uses Python's built-in `math` module).
